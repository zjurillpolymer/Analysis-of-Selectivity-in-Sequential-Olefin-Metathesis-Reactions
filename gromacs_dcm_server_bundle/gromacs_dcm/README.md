# B6 explicit-DCM simulation inputs

This directory is the compact, B6-only input bundle used by the current
neighbour-arm workflow. It contains the rigid three-site CH2Cl2-DC solvent
model, GROMACS `.mdp` files, the B6 state manifest, and protocol metadata.

The reaction-state assumption is deliberately narrow: q0 is the fixed
cross-arm first reaction; subsequent candidates are restricted to adjacent
arms. Same-arm and non-neighbour pairs remain in contact bookkeeping where
appropriate, but they are not promoted to reaction candidates by the
neighbour-only model.

The solute force field is GAFF2 with AM1-BCC charges generated by AmberTools.
The DCM model is the published CH2Cl2-DC three-site model (Fennell, Li and
Dill, DOI `10.1021/jp3002383`). The bundle is intended for explicit-solvent
contact/preorganisation simulations, not direct bond-formation kinetics.

Use the repository-level scripts with this directory as `--root`:

```bash
python analysis/setup_explicit_dcm_gromacs.py \
  --root gromacs_dcm_server_bundle --dry-run
python analysis/run_explicit_dcm_gromacs.py \
  --root gromacs_dcm_server_bundle --dry-run
```

Large run products (`.xtc`, `.edr`, `.cpt`, `.tpr`, `.gro`) are intentionally
not versioned. The manifest and compact QC tables under `results/` are the
reproducibility record; raw trajectories can be regenerated or downloaded
from the corresponding Bohrium job.
