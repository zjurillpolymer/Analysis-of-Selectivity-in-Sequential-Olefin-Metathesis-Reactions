# B6_p_C6 三重复 50 ns 显式 DCM 模拟：论文引导分析与最终结论

## 结论先行

**本轮 q0 模拟可以停止在 50 ns，不需要继续扩展到 100 或 200 ns。** 三条独立 reseed 轨迹均完整到达 50 ns，共读取 300,003 帧；66/66 个乙烯基 pair 全部通过预设收敛门槛。对当前“乙烯基距离接触”观测量，状态判断由 20 ns 的 `usable_with_caution` 提升为 `sufficient_for_current_contact_observable`。

这批轨迹给出的核心物理图景是：

1. **B6_p_C6 的近接触几何强烈偏向跨臂，而不是同臂。** 三个 replica 中，跨臂/同臂平均 sigmoid 接触比为 149–174 倍。
2. **跨臂接触并不均匀地分布在六条臂之间。** E–F、B–F、D–E、A–D、A–B 五个臂对最强，恰好构成一个不含 C 的五臂高权重闭环样骨架。
3. **C 臂是形成六臂闭环的主要几何瓶颈。** C 只承担约 2.70% 的总加权臂连接度；其最强连接 C–D 也只占跨臂接触质量的约 2.48%。任何 R6 路径都必须让 C 通过两条不同跨臂边进入闭环，因此 q0 几何本身并不会自动产生实验中的 R6 主产物。
4. **实验与 MD 的一致之处不是“q0 直接预测了 R6”，而是“q0 给出非随机初始偏好，反应历史必须把偏置网络继续推向六臂连通”。** 实验中 R6 为 53 wt%（报告类别内归一化约 55.2%）。现有逐体系拟合用正的臂对复用惩罚参数 \(\alpha=8.1\) 促进新臂对扩展，同时用 \(\gamma=0.7\) 修正反应历史传播；50 ns 的非均匀接触图为“为什么需要历史参数”提供了直接结构证据，但不能证明这些拟合参数就是实际反应能垒。

因此，本轮工作没有证明唯一的六步复分解微观路径，却已经把模型的物理边界说得更清楚：**q0 MD 可靠地描述未反应底物的接近偏好；R6 选择性主要还依赖反应后几何重排与历史传播，而不是继续延长 q0 就能解决。**

## 1. 模拟与统计设计

- 体系：`B6_p_C6_q0`，未反应 B6_p_C6 底物，显式二氯甲烷。
- 重复：3 条不同随机种子的 replica；每条 50 ns，总生产时间 150 ns。
- 轨迹：每 0.5 ps 一帧，每条 100,001 帧，共 300,003 帧。
- 接触定义：

\[
s(d)=\frac{1}{1+\exp[(d-5.0\,\mathrm{\mathring A})/0.5\,\mathrm{\mathring A}]}
\]

- 辅助敏感性检查：4、5、6、7 Å 硬阈值占有率与事件数。
- 不确定性单位：独立 replica；没有把 300,003 个相关帧误当成 300,003 个独立样本。
- 收敛门槛：材料相关 pair（承担至少 2% 总软接触质量）要求 split-Rhat ≤ 1.05 且合并 ESS ≥ 400。

为便于臂级汇总，六条臂临时标记为：

| 臂 | 乙烯基端点 |
|---|---|
| A | V1、V3 |
| B | V2、V12 |
| C | V4、V5 |
| D | V6、V7 |
| E | V8、V9 |
| F | V10、V11 |

这些 A–F 标签只用于本报告汇总，不改变原始 V1–V12 定义。

## 2. 轨迹完整性与停止判据

三条 XTC 都由 GROMACS 实际读到末帧 50,000 ps，帧数均为 100,001；完成标记也均记录为 checkpoint 连续续跑到 50 ns，没有重新初始化速度。

| 指标 | 20 ns | 50 ns | 预设门槛 |
|---|---:|---:|---:|
| 材料相关 pair 数 | 16 | 18 | — |
| 全部通过 pair | 64/66 | 66/66 | — |
| caution pair | 2 | 0 | — |
| 最大材料相关 split-Rhat | 1.052 | 1.036 | ≤ 1.05 |
| 最小材料相关合并 ESS | 322.5 | 579.0 | ≥ 400 |
| 最大材料相关积分自相关时间 | 242.6 ps | 382.9 ps | 诊断量，不设硬阈值 |

20 ns 时需要关注的两个 pair 在 50 ns 后均通过：

- V3–V8：ESS 由 322.5 提升到 770.0，split-Rhat 为 1.031；
- V7–V8：split-Rhat 由 1.052 降到 1.019，ESS 为 636.0。

ESS 并不必然随轨迹长度单调增加，因为更长轨迹可能暴露此前未发现的慢相关模式。这里 50 ns 的最大自相关时间反而更长，正说明短轨迹低估了部分慢过程；即便如此，所有材料相关 pair 仍同时通过 Rhat 与 ESS 门槛。

## 3. 接触网络的主要发现

### 3.1 跨臂近接触占绝对优势

跨臂平均软接触为 0.01089，同臂仅为 0.0000685。三个 replica 的跨臂/同臂比依次为 174.2、154.3 和 149.0。

一个容易误判的细节是：同臂端点的平均距离约 16.97 Å，反而短于跨臂的约 20.71 Å；但同臂距离分布很少进入 5 Å 附近的反应相关尾部，而跨臂分布虽然均值更长，却具有明显更肥的近距离尾部。因此，**平均距离不是合适的反应几何指标，接触尾部才是。** 这也支持继续使用平滑 sigmoid 接触而非仅比较平均距离。

### 3.2 臂对偏好稳定，但并非六重对称

15 个臂对在 20 与 50 ns 之间的分数高度一致：Pearson \(r=0.964\)，Spearman \(\rho=0.957\)。这说明延长轨迹主要是在收紧估计与发现慢模式，而不是把整个接触排序推翻。

50 ns 的前八个臂对为：

| 排名 | 臂对 | 跨臂接触质量占比 | replica SD |
|---:|---|---:|---:|
| 1 | E–F | 16.64% | 1.51 pp |
| 2 | B–F | 15.62% | 2.93 pp |
| 3 | D–E | 13.83% | 3.39 pp |
| 4 | A–D | 12.46% | 0.54 pp |
| 5 | A–B | 9.58% | 2.23 pp |
| 6 | B–E | 8.59% | 0.96 pp |
| 7 | B–D | 7.47% | 4.92 pp |
| 8 | A–E | 6.84% | 6.24 pp |

前五条边 E–F、B–F、D–E、A–D、A–B 可以连成 A–B–F–E–D–A 的五臂闭环样网络，唯独排除了 C。这个观察不是在宣称实验一定生成 R5，而是在指出：**未反应底物的高概率接近网络天然偏向五条臂，R6 必须克服 C 臂接入不足。**

### 3.3 C 臂是可重复观察到的瓶颈

各臂对跨臂接触网络的加权连接度为：E 23.45%、B 20.91%、D 18.99%、F 17.99%、A 15.96%、C 2.70%。C 比第二弱的 A 低约 5.9 倍。

C 的五条连接中，C–D 为 2.48%，C–A 为 1.21%，C–E 为 0.99%，C–B 为 0.56%，C–F 仅 0.16%。虽然 C–D 在三个 replica 中较稳定，但 C 的第二条闭环连接没有一个强候选。这是当前数据对六步成环最直接、最可操作的结构结论。

## 4. 端点级接触与慢交换

最强端点 pair 是 V9–V10，平均 sigmoid 接触为 0.0689，5 Å 内占有率为 6.22%；随后是 V3–V6、V11–V12、V6–V8、V3–V8 和 V2–V11。

端点级分数仍存在明显 replica 差异。例如 V3–V8 和 V6–V8 的 replica SD 与均值同量级，说明某些近接触由持续数 ns 的构象状态主导，而不是快速独立碰撞。5 ns 窗口曲线同样显示各 replica 在约 0.007–0.015 的跨臂平均接触范围内缓慢交换。

这与参考订书肽论文对动力学困陷的提醒一致：普通 MD 即使延长也未必遍历所有大尺度构象。50 ns 的“充分”只针对预先定义的接触统计，不等价于全局自由能面已经完全平衡。此外，三个 replica 是从共同的 base NPT 构型重新生成速度，而不是从三个明显不同的大尺度构象盆地出发；它们是独立随机轨迹，但对初始构象多样性的检验弱于参考论文。

## 5. 对实验 R6 主产物和现有模型的含义

实验报告 B6_p_C6 的 R2、R3、R4、R6 分别为 12、12、19、53 wt%，R6 是明确主产物。50 ns q0 MD 提供了两条相反但互补的信息：

- 有利证据：跨臂近接触远强于同臂，因此生成跨单体连接、最终形成多臂环在构象上是合理的；
- 限制证据：接触集中于五臂网络，C 极弱，因此仅按 q0 几何反复抽取边并不足以自然保证六臂闭环。

现有逐体系拟合给出 \(\epsilon_0=0.002316\)、\(\gamma=0.7\)、\(\alpha=8.1\)。其中正 \(\alpha\) 强烈惩罚已经使用过的臂对，促使后续反应扩展到新臂；这恰好可以把局部高概率网络向更大的商图连通结构推进。50 ns 结果因此支持以下机制层级：

\[
\text{q0 非均匀接触先验}
+\text{反应历史导致的候选重排}
\longrightarrow \text{R6 富集}.
\]

但这里的“支持”不能升级成“证明”。\(\epsilon_0,\gamma,\alpha\) 仍是由 SEC 组成监督拟合的有效参数；尤其 \(\epsilon_0\) 已经补偿了 q0、取向门控和反应后构象未显式建模等多个因素，不能直接当作化学速率常数。

## 6. 下一步怎么改模型

### 6.1 不再继续延长 q0

对当前距离接触问题，50 ns 已达到停止标准。继续到 100 或 200 ns 的边际收益较低，且不能解决“反应后结构仍沿用 q0 权重”的根本近似。

### 6.2 用这批轨迹做稳健性检验，而不是再增加自由参数

建议把三个 replica 分开转成 q0 输入，分别传播现有反应图和近最优参数集合，报告 R2/R3/R4/R6 的 replica 间范围。若 R6 结论对三个独立 q0 都稳定，才能把“MD 支撑实验”写得更强；若不稳定，就应把不确定性保留到最终产物分布，而不是用全轨迹平均掩盖。

### 6.3 下一笔计算预算应投向 C 相关的 q1/q2 状态

优先模拟会改变 C 臂可达性的反应历史，而不是继续运行未反应底物。具体可从以下候选开始：

1. 先形成高权重边后，比较 C–D、C–A、C–E 的 q1 接触是否被增强；
2. 对五臂高权重闭环样路径中的关键 q2 分支，检查 C 是否在后续步骤被“招募”；
3. 将这些反应后 MD 直接用于校准 \(\gamma\) 的传播方向和 \(\alpha\) 的臂对扩展作用，减少它们对 SEC 的纯参数补偿。

如果只允许做一个新状态，**优先使用已经建好模板的 `B6_p_C6_q1_V3_V6_cis`**。V3–V6 是 50 ns 中第二强的端点 pair，对应 A–D 臂对；它既具有充分的 q0 统计支持，又不需要重新完成一套分子构建与参数化。分析重点应放在反应后 C–D、C–A、C–E 是否相对 q0 增强。若以后愿意再新建模板，E–F 或 B–F q1 才是对最高权重五臂网络的进一步敏感性检查。

## 7. 最终可用于论文的表述

> Three independently reseeded 50 ns simulations of unreacted B6_p_C6 in explicit dichloromethane yielded converged vinyl-contact statistics (maximum material-pair split-Rhat 1.036; minimum autocorrelation-corrected ESS 579). Cross-arm near-contact was 149–174-fold stronger than same-arm contact, but the resulting arm-level network was markedly heterogeneous: five dominant edges formed a high-weight five-arm cycle-like subnetwork, whereas arm C contributed only 2.7% of the total weighted degree. These results support a non-random conformational prior for inter-arm metathesis while showing that the experimentally dominant R6 product cannot be explained by the unreacted-state geometry alone; reaction-history-dependent redistribution of candidate contacts remains necessary.

中文对应：

> 三条独立 reseed 的 50 ns 显式二氯甲烷轨迹给出了收敛的 B6_p_C6 未反应态乙烯基接触统计。跨臂近接触比同臂强 149–174 倍，但臂级网络高度不均匀：五条最强边形成一个五臂高权重闭环样子网络，而 C 臂仅贡献 2.7% 的总加权连接度。因此，MD 支持复分解前存在非随机的跨臂构象先验，同时表明实验主导的 R6 不能仅由未反应态几何解释，仍需要反应历史引起的候选接触重排。
