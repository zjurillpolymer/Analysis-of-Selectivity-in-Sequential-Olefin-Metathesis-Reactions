# C8 opposite：补齐 reuse 后的自由能比较

日期：2026-09-10。补算任务 20714508 已完成并下载。本报告补充此前的 `results/a4p_detailed_analysis/DETAILED_REPORT.md`；其中“C8 尚无 reuse PMF”的数据状态已过时，其余采样限制仍需保留。

## 结论

在当前已采样构象、指定接触区间及有限距离归一化域内，C8 opposite 的所选 switch 对 V1–V3 比 reuse 对 V3–V6 更容易进入接触区。接触概率比为 28.20，条件 bootstrap 95% 区间为 8.02–112.82。

这是所选单对的构象可及性结果，不是全部 switch/reuse 候选求和后的类别概率、化学反应速率比或产物收率。数值尚未收敛：reuse 的概率密度峰接近归一化域上边界，时间分块与截断范围均明显影响比值。不能把 28.20 或相应 α 作为已标定的最终参数。

## 概率定义与数值

接触区 C=[0.35,0.50] nm，参考区 R=[0.90,1.50] nm，归一化域 D=[0.15,3.00] nm。对未采样的 PMF bin 以直方图掩蔽，避免其输出零值产生虚假权重。这里积分的是距离边缘分布，不额外乘除径向体积因子。

| 观测量 | reuse V3–V6 | switch V1–V3 |
|---|---:|---:|
| P(C\|D) | 0.04525% | 1.27592% |
| P(R\|D) | 5.55288% | 32.95691% |
| ΔG(C/R), kJ/mol | 12.5234 | 8.4659 |

因此存在两个不同的比值：

- K_switch/K_reuse = 4.751，其中 K=P(C)/P(R)。条件 bootstrap 95% 区间为 1.958–11.108。
- P_switch(C\|D)/P_reuse(C\|D) = 28.198。条件 bootstrap 95% 区间为 8.022–112.821。

二者差异来自参考区占比：32.95691/5.55288≈5.935，故 4.751×5.935≈28.198。不能将 4.751 和 28.198 都称为同一种反应概率比。

若固定 α_D=ln[P_switch(C\|D)/P_reuse(C\|D)]，则 α_D=3.339，条件区间 [2.082,4.726]；相应 ΔΔG_D=−8.694 kJ/mol。它目前只是有限域、单对诊断值。K 指标对应的 ΔΔG 为 −4.057 kJ/mol，不能与之混用。

## 收敛与定义敏感性

| 生产时间区间，ps | K 比 | D 内接触概率比 |
|---|---:|---:|
| 100–200 | 22.74 | 38.21 |
| 200–300 | 0.825 | 3.97 |
| 300–400 | 5.16 | 23.74 |
| 400–500 | 7.59 | 136.64 |
| 300–500 合并 | 5.27 | 55.40 |
| 200–500 合并 | 2.65 | 22.83 |

四个时间块内 D 内概率比均大于 1，方向一致，但量级波动约 34 倍。K 比在第二块甚至小于 1。条件 bootstrap 的区间不能替代时间收敛或不同初态重复检验。GROMACS 文档也提醒：未充分覆盖相空间时，bootstrap 误差可能被低估。[官方 WHAM 文档](https://manual.gromacs.org/current/onlinehelp/gmx-wham.html)

reuse 在 D 内约 59.0% 的权重位于 2.5 nm 以上，21.1% 位于 2.8 nm 以上，密度峰在 2.935 nm；switch 对应为 5.43%、1.06%，密度峰为 1.635 nm。这说明 reuse 的远距离部分尚未形成可信的闭合归一化范围。

| 保持下界 0.15 nm，改变 D 上界 | 接触概率比 |
|---|---:|
| 2.00 nm | 5.15 |
| 2.40 nm | 9.57 |
| 2.65 nm | 17.04 |
| 2.85 nm | 24.60 |
| 3.00 nm | 28.20 |

这些是不同条件域，不是重复计算同一个完整平衡概率。虽然测试范围内方向均偏 switch，但不能据此断言域外尾部无影响。

将接触区在 0.30–0.60 nm 内按脚本预设的六种区间改变，概率比约为 27.51–31.90；所测接触阈值不是当前主要敏感源。改变参考区间，K 比为 1.87–7.37，D 内概率比不变。

去掉 2.75 nm 末窗口后，两条路径的 ΔG(C/R) 变化均小于 0.00001 kJ/mol；但 D 内概率比由 28.20 变为约 26.62。局部 K 对末窗口稳定，不能证明远距离归一化收敛。

## 与 C6 对照

采用前轮同一 D、C 和 25 窗口分析定义：

| opposite 所选 switch/reuse 对比 | C6 | C8 |
|---|---:|---:|
| D 内接触概率比 | 0.619 | 28.20 |
| 条件 bootstrap 95% | 0.265–1.445 | 8.02–112.82 |
| α_D | −0.480 | +3.339 |

可以说：当前 C8 单对计算呈现偏 switch 的迹象，而 C6 尚不能区分稳定偏好。不能说“已经证明 C6 偏 reuse、C8 偏 switch”的收敛反转；C6 区间跨 1，C8 仍有截断与初态采样问题。

## 下一步优先级

1. 保持单参数目标，先固定 α 的概率定义；无需增加经验拟合项。
2. 以同一批独立初态配对开展 switch/reuse 采样，检验初态差异，优先验证本次 C8 对比。单纯延长一个初态不能代替此检查。
3. 若 α 采用完整接触概率，需处理 reuse 远距离尾部。应先检查更大溶剂盒与可覆盖的距离范围，保留 GROMACS PBC 安全检查；不要直接在现有盒中无限加长拉伸窗口。
4. 只有在允许候选的对称等价性/简并度得到明确支持后，才把代表单对推广为类别概率。本轮只补了 V3–V6，并未计算另一 reuse 对 V1–V5。
